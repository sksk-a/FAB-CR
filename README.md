# Контрольная работа №2

Выполнена по практическим занятиям №7–11.

---

## Реализованный функционал

### 1. Система аутентификации (Практики 7-9)
*   **JWT Auth:** Полноценная авторизация с использованием пары токенов. `accessToken` передается в заголовке `Authorization`.
*   **Token Refresh:** Реализовал механизм обновления сессии без повторного ввода логина/пароля через `refreshToken`.

### 2. Клиентская часть (Практика 10)
*   Хранение токенов на фронтенде через localStorage
*   Динамическое отображение элементов интерфейса в зависимости от роли пользователя.

### 3. Ролевая модель (RBAC) (Практика 11)
Реализовал роли:
*   **Гость:** Только просмотр публичных страниц (регистрация/вход).
*   **Покупатель:** Просмотр каталога товаров и доступ к личному профилю.
*   **Продавец:** Возможность добавлять и редактировать свои товары.
*   **Администратор:** Полный доступ к управлению пользователями и любым контентом.
