# Контрольная работа №3 (https://github.com/sksk-a/FAB-CR/tree/main/kr3)

Выполнена по практическим занятиям №13–17.

---

### Практика 13: Service Worker
В этой работе я заложил основу для офлайн-режима, изучив жизненный цикл Service Worker.
*   **Реализовано:**
    *   Регистрация скрипта `sw.js` в основном файле `app.js`.
    *   Кэширование статических ресурсов (HTML, JS) через событие `install`.
    *   Сохранение и отображение заметок с использованием `localStorage`.

### Практика 14: Web App Manifest
Здесь я превратил сайт в устанавливаемое приложение, добавив метаданные для браузеров и ОС.
*   **Реализовано:**
    *   Создан файл `manifest.json` с описанием имени, цветов темы и режима отображения `standalone`.
    *   Сгенерирован и подключен набор иконок (от 16x16 до 512x512 пикселей).
    *   Настроено кэширование манифеста и иконок внутри Service Worker.

### Практика 15: HTTPS + App Shell
Я обеспечил безопасность приложения и мгновенную скорость загрузки интерфейса.
*   **Реализовано:**
    *   Генерация локальных SSL-сертификатов через `mkcert` и запуск Node.js сервера по протоколу HTTPS.
    *   Разделение интерфейса на «каркас» (`index.html`) и динамические страницы контента (`home.html`, `about.html`).
    *   Логика динамической подгрузки страниц через `fetch` без перезагрузки вкладки.

### Практика 16: WebSocket + Push
В этой практике я добавил в приложение функции реального времени и системные уведомления.
*   **Реализовано:**
    *   Сервер на Node.js с использованием библиотек `socket.io` и `web-push`.
    *   Двусторонняя связь: при добавлении заметки сервер рассылает событие `taskAdded` всем клиентам.
    *   Обработка события `push` в Service Worker для показа уведомления, когда браузер закрыт.

### Практика 17: Детализация Push (Напоминания)
Я доработал систему уведомлений, превратив её в полноценный планировщик задач.
*   **Реализовано:**
    *   Форма создания заметок с выбором даты и времени через `datetime-local`.
    *   Хранение активных таймеров на сервере в коллекции `Map` и автоматическая отправка уведомления по расписанию.
    *   Интерактивные уведомления: в Push-сообщение добавлена кнопка «Отложить на 5 минут».
